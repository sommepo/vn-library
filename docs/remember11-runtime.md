# Remember11 PS2 runtime (2026-09-21)

The owner's **SLPM-65550 v1.02** import now executes original Japanese scenarios
in the shared browser reader. This required a new KID interpreter; CLANNAD's
HuneX adapter could not run it. Other KID titles/releases remain untested.
The [initial trial](remember11-investigation.md) is historical evidence of that
failed unmodified import, not the current support status.

## Recovered content and execution

`vnkit/adapters/remember11_script.py` parses instruction boundaries and reachable
control flow using metadata from the fingerprinted executable. It does not sort
or concatenate recovered strings. `web/adapters/remember11-engine.mjs` executes
the resulting versioned bytecode records through the shared reader contract.

- 167 parsed script resources, 128,290 instructions; 123,689 in story resources
  0–154. Four other MAC members (155–158) are native lookup tables, not scenarios.
- Native STARTUP resource 159 enters PR_01; the original prologue selects the
  chapter using local word 42. Conditions, signed 16-bit arithmetic, variable/bit
  banks, branches, calls/returns, choices, random state and script loading execute
  from source. Unknown commands/parameter variants stop with a source location.
- Source text instructions supply strict CP932, speaker prefixes, page controls,
  read IDs and voice indices. The shared reader receives complete logical segments
  independently of typewriter rendering; selection remains ordinary DOM text.
- 487 backgrounds, 158 CGs and 947 portrait base frames, at original dimensions.
  Neutral faces are already part of the base portrait; extra eye/mouth planes
  are currently omitted. Character X is a centre anchor, unlike BG/EV placement.
- All 12,158 voices and 468 effects converted to FLAC. Original ADX loop metadata
  is retained for effects. Text-to-voice association comes from instruction fields.
- 74 music resources: 37 looping/no-loop pairs. Original SQ and instrument banks
  are rendered with FluidSynth; these are **not 74 different compositions**, nor
  bit-identical SPU2 recordings. Browser loop seeking is not guaranteed gapless.
- All 16 movies converted, with decoded video and (where present) PCM hash checks.
  MV08 is a video-only PSS, established by a bounded packet walk; it is not missing
  audio. No substitute media was downloaded.

`private/library/remember11-live` is the standalone import. The ISO is needed to
rebuild it, not to read it. Import/validation intentionally return **3**, because
native presentation and extras are incomplete; **2** means an actual failure.

## Shared reader features

The same reader supplies 15 manual slots, quicksave/load, autosave/resume,
save/progress export/import and deletion, optional home-server shared saves,
searchable voiced backlog, bookmarks, Auto, Skip read, VM-driven Next choice,
global pause, mobile/fullscreen, CRT, theme/opacity/font controls and separate
music/voice/effect volumes. Source endings return to its menu.

Text selection/copy, opt-in automatic clipboard, live companion and authenticated
WebSocket output use the existing [text/activity contract](text-and-statistics.md).
Daily totals, four-hour sessions, 04:01 day boundaries, session deletion/reset and
activity backup stay independent of game saves. Restores retain occurrence IDs;
unpresented Next choice traversal emits no dialogue and adds no study characters.

Persistent native globals/catalogs survive slot loads and new playthroughs through
the existing progress bank. Kokoro clear bit 84 unlocks Satoru; Satoru clear uses
bit 100. Bad endings do not set these completion flags. Debug/manual completion
is labelled and backed up. It cannot reconstruct every cross-chapter decision
from somebody else's playthrough. Completed-route inherited read paths use one
fixed, fresh-entry VM replay per chapter. They affect red text/Skip read only;
alternate branches remain unread and study totals are unchanged. The private
signature-bound sidecar is generated by `scripts/build-remember11-read-paths.mjs`.

## Evidence and explicit limits

Static validation of the whole import finds **zero parse failures and zero
unresolved direct references**. There are **16 unsupported command sites**, all
in original DBG_* resources: native save UI, self-modifying script operations and
graph animation. They are fail-closed, not quietly bypassed. Runtime-loaded media
references are additionally checked on use; static direct-reference coverage is
not proof of every possible dynamic path.

Headless first-option checks on the actual import reached:

| Entry | Text segments | Choices | Scripts | Save/restore checks | Result |
| --- | ---: | ---: | ---: | ---: | --- |
| Fresh Kokoro | 10,155 | 50 | 51 | 242 | Source bad ending, no chapter clear |
| Manually unlocked Satoru | 4,525 | 25 | 24 | 70 | Source bad ending; not natural unlock evidence |

These checks simulate timing/movie completion. They are separate from browser
checks and do not establish all-route compatibility. Private reports are under
`private/remember11/kokoro-first-v2` and `satoru-first-v2`. The bounded DFS and
guided replay harnesses retain their source paths/checkpoints privately.

The subsequent bounded DFS explored 79,965 presentations and 511 choice edges,
reaching ten distinct source endings. Those are traversal counts including
revisits, **not unique text coverage**. Its Kokoro success path was then replayed
from a fresh entry: **12,948 text segments, 58 choices, 67 scripts**, ending at
`00073-COEP_01.BIP:0928` with bit 84 earned naturally and no manual completion.
All 58 choice checkpoints restored exactly. The separate guide-suggested Kokoro
path reached a source bad ending; it is retained as a failed expectation, not
quietly counted as a successful clear.

Using that source-earned Kokoro progress, Satoru reaches
`00154-SAEP_06.BIP:08b4` and sets bit 100: **14,265 segments, 60 choices, 80 scripts**.
All 60 choice checkpoints restore exactly. This run continued from verified
checkpoints while correcting guide/source wording differences; the final recorded
choice path is independently replayed from a fresh entry by the read-path builder.
These two completed paths establish basic chapter playability, not every ending,
every cross-playthrough variant or PS2 presentation fidelity.

Native read flags are compact 32-bit words in the save catalog. Earlier verbose
snapshots migrate without changing their native read count or learning history.
The real post-Satoru checkpoint retains **26,737 native read flags** in a roughly
25 KiB save. `tests/remember11-large-save.mjs` verifies all 15 manual slots plus
three automatic/quick positions and both progress records against the unchanged
shared server limits: the tested bank is 499,385 bytes. Do not increase server
limits to compensate for accidentally storing one long key per native read flag.

Initial browser runs exposed a portrait-origin bug, now corrected. Test-harness
fixes included asynchronous IndexedDB/slot waits, the correct quicksave key and
scoping Save location to the correct game in the library. Save timestamps and
read-only shared-bank caching were also corrected. Earlier failed reports remain
private historical evidence; only the named completed runs are passes.

The final Python regression suite passes 70 tests; the Node run passes all ten
test files, including CLANNAD, shared-reader tests and Remember11's eight isolated
VM cases. Import assembly ran again with identical outputs and its expected exit
3. `final-cli-validation-v2.json`, `final-validation.json`, the test logs and both
read-path replay logs are under `private/remember11`. The final compact-state
replay reproduces both source endings and the same text-ID sets.
The last BGM change applies native 0/64/128 gain immediately through the shared
music-volume multiplier; fade envelopes remain degraded. The 200-segment smoke
and both complete recorded paths pass after that change (`final-route-replay.log`).

Remaining differences: native palette/screen effects, fades, UV/scale motion,
eye/mouth animation, clock/title artwork, detailed in-text timing, asynchronous
movie overlays, music envelopes, native TIPS/chronology/gallery interfaces and
exact source speaker/window styles. The native TIPS unlocks are retained, but
their original menus are not implemented. The compact Latin glyph currently
decodes as CP932 ⑳; its font mapping is unverified. Unknown percent controls fail.
Ruby is supported by the reader, but this edition's exact ruby/font-control
coverage has not been established. No PS2/emulator audiovisual comparison was
performed. Android, Z13 audio and the user's dictionary extension require device
checks. Do not claim full-game fidelity or an exact completion percentage.

## Format/native evidence for maintainers

- Fingerprint gate: ELF SHA-256
  `644566b01b67e5795a3ac5064a70e69f777e77a7de855d514594dbd7e3949e92`.
  Static reads/disassembly only; the original executable was not run.
- Dispatch table `0x1e1c48` contains 135 entries. The old instruction-size table
  at `0x1e22a0` needs the audited corrections in `remember11_script.py`; trusting
  it blindly splits later commands. Operand read/write functions are at
  `0x11f530` / `0x11f5f8`, with signed words and packed flag banks.
- Operand tags: 0x4000 global words, 0x6000 local words, 0x8000 global bits,
  0xa000 local bits; low 13 bits index the bank. Other values are signed literals.
  Native conditional evaluation is at `0x122250`. Only the observed index-zero
  computed-entry form is enabled; unaudited dynamic forms fail.
- Text opcodes 0x1f/0x73 hold text offsets/read IDs/voice IDs. Choice opcodes
  0x25/0x74 preserve condition operands, result destinations and branch targets.
  Native RNG uses a 64-bit LCG; save state retains its full integer string.
- Native movie table `0x1e0c70` supplies names/CG identifiers. Graphics resources
  use high-nibble categories and original archive ordinals. CHR draw `0x1303e0`
  subtracts half-width from its X anchor and subtracts source Y.
- BIP images have five or ten offset sections. The final two delimit tile pixels;
  assuming a five-section header for all portraits produces out-of-range tiles.
  Packed 16×16 atlas cells contain 14×14 visible tiles and one-pixel gutters.
- BGM BIP offset units vary (4 or 16); require a unique valid IECS header layout.
  SQ may end in an IECSgnoS trailer. MIDI channel pressure (D0) occurs in this
  game and needs the scoped VGMTrans patch. Missing unused programs are allowed;
  attempting to play an unmapped instrument remains a conversion failure.

Native addresses/opcode logic belong in this adapter, not shared reader code.
Recovered tables and choice paths remain private. See [import commands](remember11-import.md)
and [provenance](provenance.md).
