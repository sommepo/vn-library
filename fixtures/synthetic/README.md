# Original reader test fixture

`content.json`, all Japanese text, SVG artwork and tone audio are original
MIT-licensed toolkit test content. This fixture is **not a converted game** and
does not demonstrate support for the supplied disc.

Rebuild deterministically with `python3 fixtures/synthetic/build.py`.
It exercises two branches, variables, a condition, a shared call/return,
115 successive test pages, repeated sentences at different source IDs,
ruby, background and sprite changes, a timed instruction, music, an effect,
and an optional voice-channel **test tone, not voice acting**.

The final choice can revisit the same source locations to test rereading.
